Qwen3-0.6B WebGPU: original vs optimized kernels

Runs the same custom WebGPU decode stack on one prompt with different kernels and compares tokens/sec. Every variant runs entirely on the GPU with the embedding table resident, and all must emit identical token ids.

Three kernel sets:
  • original kernels — block-parallel q4 matvec; LM head reading f32 weights across 75 submit/readback round-trips with the argmax scanned on the CPU.
  • original LM head + optimized q4 — isolates the matvec's contribution.
  • optimized kernels — word-parallel q4 matvec; resident f16 LM head with a two-stage GPU argmax returning 8 bytes per token.
Run A/B compares original against optimized. Run all three adds the mixed variant so you can attribute the speedup to each rewrite.
This is a base model with no chat template, so it continues your text rather than answering it. "write a poem" continues as "write a poem about…".
